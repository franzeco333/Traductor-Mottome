# Traductor Mottome (Mottome Translator)
<img width="500" height="500" alt="Mottome App" src="https://github.com/user-attachments/assets/533d1667-6e67-42e0-9c7a-c44ce971a2fd" />
 
Entorno de trabajo independiente para Windows destinado a la traducción de juegos de Ren'Py; creado por y para una comunidad de Discord dedicada a traducir al español juegos otome (novelas visuales dirigidas a un público femenino).
 
Standalone Windows translation workbench for Ren'Py games, created for and by a Discord community dedicated to translating otome games (girls-targeted visual novels) into Spanish
